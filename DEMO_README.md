## 🚀 Quick Start Guide

### Prerequisites
- Python 3.8 or higher
- pip (Python package installer)
- 4GB+ RAM recommended for AI features

### Installation Steps

1. **Extract the Project**
   ```bash
   unzip one_health_ai_platform_enhanced.zip
   cd one_health_ai_platform
   ```

2. **Install Dependencies**
   ```bash
   pip install -r enhanced_requirements.txt
   ```

3. **Initialize Sample Data** (Optional)
   ```bash
   python generate_sample_data.py
   ```
   Choose option 1 to generate comprehensive demo data.

4. **Run the Enhanced Application**
   ```bash
   streamlit run enhanced_app.py
   ```

5. **Access the Platform**
   Open your browser and navigate to `http://localhost:8501`

### Alternative: Run Original Version
To compare with the original version:
```bash
streamlit run app.py
```
